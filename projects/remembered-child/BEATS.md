# Visual argument

You can retain a memory of the child while no longer having that child's body. A persistent photographic memory and a changing, anonymous body outline make this contrast visible. The outline is a conceptual illustration, not a literal face-aging simulation or scientific growth measurement.

# Design

1920×1080, 30fps, exactly 300 frames. Manrope variable bold, charcoal #101416, ivory #eeeae0, gold #dcbb7f. Wide safe margins; selective labels instead of full-sentence subtitles. Movement has a destination. The photo's identity remains unchanged. Fragments only occur while the former body contour dissolves. No decorative dust field, generic noun icons, faces morphing into unrelated people, or gratuitous 3D.

# Engine

Remotion for precise phrase timing, audio and native rendering; React/SVG for the comparison and contour transformation. This is the smallest dependable stack for this visual argument. No additional paid service or asset is required.
